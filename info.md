# VOOL Integration

A Home Assistant custom integration for VOOL EV Chargers and Load Management Controllers (LMC) via Cloud API.

## Features

- Real-time monitoring: Power, current, voltage (per phase)
- Support for both VOOL Charger (Wallbox) and LMC devices
- Cloud-based API connection

## Configuration

After installation, add the integration via Settings → Devices & Services → Add Integration → VOOL.

You'll need:
- VOOL account email
- VOOL account password
- LMC Device ID
- Wallbox Device ID

Device IDs can be found in your VOOL account at https://app.vool.com/devices/{device-id}/overview
